# Clanda App UI/UX

A portable, dependency-free front-end recreation of the Clanda mobile wallet preview.

## Open it

Open this folder in VS Code, then open `index.html` in a browser. No install, build, or server is required.

## Included

- Responsive mobile wallet home with NGN and USD balance views
- Home, Transactions, Scan & Pay, Services, and Profile tabs
- Search and category filters for transactions
- Demo add-money, transfer, and bill-payment flows
- Balance visibility, light/dark theme, QR demo, and profile controls
- Custom inline SVG icons; no emoji icon assets

This is a front-end demo. It does not connect to a bank or move real money.
